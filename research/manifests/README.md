Contents (generated by `research/tools/make_inventory.py`):

- `sha256.txt`: `sha256sum`-format hashes of the 724 files.
- `inventory-summary.txt`: file count, total bytes and breakdown by extension.

Rules:
1. Never write, rename or delete inside the install path.
2. Never run an unknown binary; the game is launched only via Lutris.
3. Any extraction is written to `extracted/`, preserving the original.
