# Game inventory (Phase Two)

`GAME_PATH`: `$SC_INSTALL` (Battle.net install, `.../Program Files (x86)/StarCraft`)
(~5.5 GB, build 1.23.10.13515). Read-only; verified 2026-10-28
(`.build.info` sha256 matches the manifest).

## Manifests

- `manifests/inventory.csv`: 724 files (header + 724 rows),
  with relative path, size, extension, `file` type, sha256, classification,
  notes. Generated by `tools/make_inventory.py` (formerly a copy of `analysis/file-inventory.csv`).
- `manifests/sha256.txt`: 724 hashes.
- Total: 5 879 150 935 B.

## Identification tools

`find` + `file` + `sha256sum` (+ `objdump` for PE). No indiscriminate
decompression; CASC/MPQ are read with `src/retail.rs` and C++ extractors.

## Unrecognized

`analysis/discovery/unrecognized-files.csv`: 239 rows with
`provisional_classification == unknown`. Composition: 128 `.htm` +
48 `.idx` + 47 `.index` + minor rest. The `.htm` files are CEF locale (known
format, secondary content); the `.idx`/`.index` files are CASC indices
(format known from the container structure). They remain "non-priority",
not mysterious formats: see `docs/unresolved-questions.md`.
