# starcraft-re-recomp (vault index)

Working notes for the single Rust engine in `engine-rust/` (a deterministic
StarCraft 1.23 engine and its playable client). Rules: [[OBSIDIAN]].

## New here? Read in this order

1. Repository `README.md`, `PROGRESS.md` (what exists, what is missing) and `AGENTS.md` (process rules).
2. [[where-to-look]]: which files and tests own each area.
3. [[retail-recordings]]: the retail evidence behind timing and layout.
4. [[retail-file-glossary]]: short retail names (`MBRF`, `gluscore`, `stat_txt`, …).
5. Open work in your area: the **Open work by area** view below, or
   `python3 scripts/vault_check.py --open --area <area>`.
