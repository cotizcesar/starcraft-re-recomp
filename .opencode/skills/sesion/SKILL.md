# Work session (starcraft-re-recomp)

Paths relative to the project root. Vault: `obsidian/`.

## Opening

1. Read `obsidian/starcraft-re-recomp.md` (index).
2. Read `obsidian/20-Contexto/` and the latest note in `obsidian/30-Sesiones/`.
3. If needed, check `PROGRESS.md` and `research/docs/PROJECT-STATUS.md`.

## Closing

1. Create `obsidian/30-Sesiones/YYYY-MM-DD-topic.md` from
   `obsidian/templates/sesion.md` (fill in real frontmatter).
2. Each relevant decision goes to `obsidian/10-Decisiones/topic-name.md`
   from `obsidian/templates/decision.md`, linked from the session.
3. No secrets. `[[wiki-style]]` links, descriptive filenames,
   `origen: opencode` in frontmatter. Mark FACT vs INFERENCE.
