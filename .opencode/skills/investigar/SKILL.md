# Research (starcraft-re-recomp)

1. Search the vault first: `obsidian/20-Contexto/` plus grep for the topic.
   If a note exists, extend it instead of duplicating.
2. Research in code and, if needed, on the web.
3. Save to `obsidian/20-Contexto/topic-name.md` from
   `obsidian/templates/contexto.md`: overview, key concepts,
   connections to `[[existing notes]]`, sources.
4. Descriptive filename, full frontmatter, `origen: opencode`.
   No secrets. Mark FACT vs INFERENCE.
