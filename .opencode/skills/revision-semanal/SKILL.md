# Weekly review (starcraft-re-recomp)

1. Read `obsidian/30-Sesiones/` notes for the week (Mon–Fri).
2. Extract: done, still open (and why), patterns, new notes
   in `10-Decisiones/` and `20-Contexto/`.
3. Generate `obsidian/30-Sesiones/YYYY-WNN-weekly.md`:
   what got done, what did not, patterns, next week priorities.
4. Ask before saving whether wins or lessons should be added.
